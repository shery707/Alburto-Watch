# Alberto Watches — Student eProject

**Project team:** Arham Gohar · Sheryar · Huzaifa Rehman

A responsive single-page luxury watch retail and service website based on the supplied Alberto Watch Company eProject specification.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is recommended for CDN libraries, Google Fonts and remote photography.

## Included features
- Responsive single-page layout and sticky navigation
- Luxury, Vintage, Smart and Classic product filters
- Product details in Bootstrap modal windows
- Sample product price list
- Click-to-enlarge image gallery
- Technology, Store Locator, Support, About, Team and Contact sections
- Browser-local visitor counter
- Live date/time ticker and visitor-initiated geolocation
- Front-end contact form demonstration

## Files
- `index.html` — page structure
- `assets/css/style.css` — styling and responsive design
- `assets/js/products.js` — sample product catalogue
- `assets/js/script.js` — interactions and rendering
- `PROJECT_REPORT.md` — project report, activity flow, data flow, test cases and assumptions
- `TEST_DATA.csv` — concise test data

## Important assumptions
The product catalogue, prices, showroom address, email and phone number are demonstration placeholders. Replace them with verified company details before production. The contact form does not send data to a server. The visitor counter is local to the current browser. Geolocation is requested only after the visitor clicks the ticker location label.
